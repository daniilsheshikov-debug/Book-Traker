# Book Tracker

**Автор:** Шешиков Даниил 
**Дата:** 12.05.26

## Описание
Консольное приложение для ведения списка прочитанных книг.  
Позволяет добавлять, редактировать, удалять книги, фильтровать по жанру или количеству страниц,  
а также хранит историю выполненных действий. Данные сохраняются в формате JSON.  
Приложение построено по архитектурному шаблону MVC и использует принципы ООП.

## Как запустить
1. Убедитесь, что установлен Python 3.6 или выше.
2. Поместите файлы `book_tracker.py` и `books.json` в одну папку.
3. Запустите скрипт:
   ```bash
   python book_tracker.py
